collected course from `races` but never passed it into the audit write.

- Added `UNIQUE (race_id)` constraint to `sigma_audits` via Management API

### 3. scripts/generate_sigma_report.py — created

Reads `sigma_audits` + `velo_post_race_reviews` + `learned_patterns` for a given date.
Writes `reports/daily/sigma_forensic_YYYY-MM-DD.md`.

Sections:
- DAY SUMMARY (win/place/miss counts, avg SP, longshots)
- TIER TRUTH all-time cumulative from learned_patterns
- TODAY'S RACES — WINS / PLACED / MISSES tables with signal gap column
- MISS REASON HIERARCHY (today vs all-time vs category)
- TRACK CHAOS LOG (course/chaos/pace/tier/outcome per race)
- DOCTRINE STATUS (B-tier gate, pending items)
- WHAT CHANGED SINCE YESTERDAY (operator-populated)

Run: `python scripts/generate_sigma_report.py [--date YYYY-MM-DD]`
