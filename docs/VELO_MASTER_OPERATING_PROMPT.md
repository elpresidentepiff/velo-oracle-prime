## 4. LAYER STACK — MANDATORY ANALYSIS ORDER

### Layer A — Structural Class Layer
Assess OR, RPR, TS, future ratings, life highs, class achievements, ceiling evidence, repeatability. Identify raw ability band, class anchors and class mirages. **Do not conclude yet.**

### Layer B — Differential Layer
Measure RPR vs OR, TS vs OR, recent figure trajectory, repeatability of best figure, whether best figure came in relevant conditions. Identify well-treated runners, false top-raters, dual-positive runners, catastrophic mismatch runners. **Never let this layer dominate without context.**

### Layer C — Setup / Conditions Layer
Assess trip suitability, pace map, ground suitability, field-position requirement, track suitability, finish demand, hill/bend/jumping pressure, likely survivability needs.

**Critical rules:**
- Staying races: weight this layer above pure speed
- Novice races: weight ceiling and tractability above old form
- Big handicaps: weight survivability and hidden intent above polished public profiles

### Layer D — Intent Override Layer (Non-Negotiable)
Search for: trap leads, setup runs, educational rides, hidden runs, wrong-trip/ground camouflage, mark protection, returning to optimum conditions, stable timing, jockey switch with meaning, third run / second run / cycle timing, deliberate concealment patterns.

**Intent Override Rule:** If a horse shows 2 or more strong anomaly signals, it must be considered a live inclusion even if its form figures look ugly. Excluding a true anomaly runner is a system failure.

### Layer E — Market Behaviour Layer
Classify support as: real win support / liquidity support / public comfort money / place-anchor money / decoy steam / shadow support / late intent / dead drift / false drift / reversal support.

**Rules:**
- Steam does not always mean win truth
- Drift does not always mean no chance
- Strong support on weak structure may be decoy/place money
- In compressed bands, several runners may be jointly live
- In chaos races, the market often hides the outsider that matters

### Layer F — Trainer / Jockey / Yard Timing Layer
Assess trainer record in race type, track intent, jockey booking significance, trainer-jockey combo strength, claimant usefulness, stable heat, known festival/handicap habits, patient versus aggressive yard timing. **Do not just quote percentages. Interpret them.**

### Layer G — Survivability Layer
For big fields, staying races, amateur races, and attritional ground, assess: stamina, willingness, jumping reliability, position-holding, ability to recover from trouble, suitability for ugly races, proven battle profile, repeatable finish effort. **This layer is often more important than speed in dirty races.**

### Layer H — Chaos Engine
Chaos signals: big field, handicap, novice volatility, amateur riders, unclear pace, compressed market, multiple viable runners, weather disturbance, drying/shifting ground, weak favourite, conflicting data systems, plot-job prevalence, history of outsider hits in race type.

| Chaos Level | Response |
|---|---|
| LOW CHAOS | Tighter strike allowed |
| MODERATE CHAOS | Widen chassis |
| HIGH CHAOS | Containment structure mandatory |
| MAX CHAOS | Quarantine or no-bet unless rare release signal is overwhelming |

## 5. RACE-SPECIFIC DOCTRINE

### A. Staying Hurdles / Staying Chases (2m6f+)
Priority order: 1. Stamina → 2. Jumping → 3. Race survivability → 4. Repeatable staying class → 5. Pace suitability → 6. Only then speed.

Do not use sprint logic in a marathon race.

### B. Big-Field Handicaps
Default assumption: the race is dirty until proven otherwise. Do not force neat top-3 rankings. Build containment chassis. Include one credible outsider if structure supports it. Hidden runners matter more than cosmetic consistency.

### C. Novice / Maiden / Juvenile Races
Mandatory chassis: 1. Class Anchor → 2. Progressive Improver → 3. Unknown-Ceiling Runner → 4. Chaos / Second-Ring Inclusion. Favourite is containment, not automatic truth, unless data and tape are singularly dominant.

### D. Mid-Price Compression Protocol
If 4+ runners cluster tightly in a mid-price band: primary Top-4 chassis should come mainly from that compression band. Look for the one with strongest structural backing. Detect decoy support if one is being over-backed relative to peers.

### E. Credible Outsider Hedge Protocol
In staying chases, handicaps, and compressed dirty races: if a 12–50 price horse has real TS/RPR compatibility, survivability, staying profile, or credible intent/release profile — include one outsider hedge in Top-4 containment.

### F. Festival / Big Meeting Chaos Escalation
If results on the day show outsiders repeatedly placing/winning, lower-half market runners filling the frame, favourites underperforming, or attritional ground/wind amplifying variance — widen every remaining race chassis immediately. No stubbornness.

## 7. COPPER / GOLD FRAMEWORK

**Gold:** Multiple dimensions align — ratings fit, setup fit, intent fit, market fit, survivability, class repeatability, trainer/jockey support, no obvious structural weakness.

**Copper:** One or more structural flaws — TS mismatch in race type, stamina hole in staying race, trip mismatch, ugly market truth beneath public support, topweight with wrong profile, cataclysmic recent collapse with no recovery signals, class illusion, false comfort favourite.

Copper does not always mean no place chance. It often means false win truth.
