## What RPDC Is

RPDC (Racing Post Data Context / Release Candidate) is the horse-career memory layer. It answers: "Is this horse at a release point in its career cycle?" Tags like `CYCLE_RUN_2`, `MARK_READY`, `COURSE_RETURN` describe where the horse is relative to its historical form.

RPDC is NOT a daily sidecar. It is horse-career memory. It should span a horse's entire scorable history. The current architecture treats it as a daily batch job — that is the root failure.


## Tag Definitions (current production weights)

| Tag | Weight | Condition |
|---|---|---|
| `MARK_READY` | 3.0 | current_or ≤ last_winning_or |
| `BELOW_LAST_WIN_MARK` | 2.0 | current_or < last_winning_or |
| `MARK_NEAR` | 1.5 | current_or 1–3 above last_winning_or |
| `CYCLE_RUN_1` | 1.0 | First run of campaign year |
| `CYCLE_RUN_2` | 1.2 | Second run of campaign year |
| `CYCLE_RUN_3` | 1.3 | Third run of campaign year |
| `FRESH_RETURN` | 1.5 | 22–45 days since last run |
| `LONG_ABSENCE` | -0.5 | >90 days since last run |
| `STABLE_WARM` | 1.0 | trainer win_rate ≥ 15% in local window |
| `COURSE_RETURN` | 1.2 | Previous win at today's course |
| `DISTANCE_RETURN` | 1.0 | Previous win at today's distance (after divergence) |
| `WIN_STREAK` | 1.5 | ≥2 wins in last 5 runs |
| `PLACE_FORM` | 0.8 | Last run was a place, no recent win |

Cash window threshold: `release_score ≥ 3.0`

## What Must Not Be Mutated

- `data/velo_prime_verdicts_{date}.json` — official prediction record. Do not backpatch.
- `velo_verdicts` (Supabase) historical rows — do not overwrite RPDC fields in old predictions. Mutations to historical scoring artifacts require separate Council approval.

---

## Canonical Design Recommendation

RPDC should not be rebuilt daily from scratch. The architecture should be:

```
rpdc_horse_memory table (or local canonical JSONL)
  → versioned snapshot per scoring run
  → queried by run_prime_today.py at scoring time
  → separate from velo_verdicts (prediction history)
```

Historical predictions stay historically honest. Future predictions read from the rebuilt RPDC memory. See `docs/engineering/RPDC_SUPABASE_BACKFILL_PROPOSAL.md` for architecture detail.
