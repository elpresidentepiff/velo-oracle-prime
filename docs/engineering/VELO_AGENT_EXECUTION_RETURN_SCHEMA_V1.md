# VELO Agent Execution Return Schema V1

Every agent run must return the following fields.

## Required Fields

- `TASK_TYPE`
- `COMMANDS_RUN`
- `EXIT_CODES`
- `FILES_READ`
- `FILES_CREATED`
- `FILES_CHANGED`
- `FILES_PATCHED`
- `FILES_REVERTED`
- `FILES_STAGED`
- `FORBIDDEN_FILES_DIRTY`
- `FORBIDDEN_FILES_STAGED`
- `TESTS_RUN`
- `TESTS_PASSED`
- `TESTS_FAILED`
- `SUPABASE_WRITES_ATTEMPTED`
- `LIVE_SENTIENT_STATE_TOUCHED`
- `LIVE_PLAYBOOK_G_TOUCHED`
- `HFS_READ_ATTEMPTED`
- `HFS_WRITES_ATTEMPTED`
- `MODEL_WEIGHTS_CHANGED`
- `PRODUCTION_SCORING_CHANGED`
- `TRAINING_ATTEMPTED`
- `HFS_TRAINING_SAFE`
- `COMMIT_ALLOWED`
- `COMMIT_CREATED`
- `COMMIT_HASH`
- `BLOCKERS`
- `NEXT_GATE`
- `VERDICT`

## Optional Fields

- `MISSION_NOTES`
- `COUNCIL_NOTES`
- `WARNING_FLAGS`
- `ARTIFACT_SUMMARY`

## Allowed Verdicts

- `PASS`
- `PARTIAL`
- `BLOCKED`
- `FAIL`

## Safety Fields

Safety fields must always be explicit booleans or enums:

- `SUPABASE_WRITES_ATTEMPTED`
- `LIVE_SENTIENT_STATE_TOUCHED`
- `LIVE_PLAYBOOK_G_TOUCHED`
- `HFS_READ_ATTEMPTED`
- `HFS_WRITES_ATTEMPTED`
- `MODEL_WEIGHTS_CHANGED`
- `PRODUCTION_SCORING_CHANGED`
- `TRAINING_ATTEMPTED`
- `HFS_TRAINING_SAFE`

## Commit Fields

- `COMMIT_ALLOWED`
- `COMMIT_CREATED`
- `COMMIT_HASH`
- `FILES_STAGED`
- `FORBIDDEN_FILES_STAGED`

## Next Gate Field

`NEXT_GATE` must name the next allowed technical gate, not a vague intention.
